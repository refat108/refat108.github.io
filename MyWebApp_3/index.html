CDC Health Stats Visualizer - New Mexico

This interactive web map presents selected CDC PLACES health measures across New Mexico census tracts. Users can explore spatial patterns in health outcomes, preventive care, risk behaviors, and health status across communities.

The maps use crude prevalence estimates from CDC PLACES data and link them to New Mexico census-tract boundaries. Popups provide tract-level values, population information, and 95% confidence intervals where available.

About the project

CDC Health Stats Visualizer - New Mexico is an interactive web mapping project that presents selected CDC PLACES health measures at the census-tract level across New Mexico. The map is designed to help users explore how health-related conditions and needs vary across different communities within the state.

The project focuses on several major categories of health indicators, including health outcomes, preventive care, health risk behaviors, and health status. By organizing the data into these categories, the web map allows users to examine both medical and social dimensions of health in a spatial format.

Users can select different indicators from the dropdown menus to update each map. Each census tract is shaded according to the selected measure, allowing users to identify geographic patterns, compare areas, and observe where certain health conditions or needs appear more concentrated. Clicking on a census tract opens a popup with additional information, including the selected prevalence estimate, population information, and confidence intervals where available.

This project uses CDC PLACES data linked to New Mexico census-tract boundary data. CDC PLACES provides local-level estimates for chronic disease, prevention, health behaviors, and related health measures. The census-tract geography makes it possible to examine variation within counties and across smaller communities rather than only at the state or county level.

The purpose of this project is educational and exploratory. It is intended to support visual analysis, public health learning, and community-level comparison. The map can help students, researchers, public health professionals, and community members better understand spatial differences in health measures across New Mexico.

This web map was adapted from the GeoAIR Lab web-mapping framework developed by Dr. Liping Yang. The original framework was modified for a CDC PLACES-focused analysis of New Mexico health measures while preserving the interactive mapping structure of the original lab project.

Data Explanation

This project uses CDC PLACES health measure data for New Mexico census tracts. Each row in the dataset represents one census tract, and each health measure represents an estimated population-level percentage for that tract.

Measures ending in _CrudePrev show crude prevalence estimates. These values are displayed on the maps as percentages. Measures ending in _Crude95CI provide the 95% confidence interval for the corresponding estimate and are shown in the map popups when available.

The data are joined to census-tract boundaries using tract FIPS codes. The CSV field TractFIPS is matched with the GeoJSON field GEOID. This allows each census tract polygon on the map to display the corresponding CDC PLACES health measure values.

The maps are intended for exploratory and educational use. They show geographic patterns in population-level health estimates and should not be interpreted as individual-level health records or clinical diagnoses.
